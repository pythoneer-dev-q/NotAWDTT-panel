# qWDTT: повторы TURN и имена устройств

Патч [qwdtt-turn-retry.patch](../patches/qwdtt-turn-retry.patch) подготовлен для исходников [studasd/qWDTT](https://github.com/studasd/qWDTT) на ревизии `dd45f39`.

В каталоге qWDTT примените:

```bash
git apply /path/to/NotAWDTT-panel/patches/qwdtt-turn-retry.patch
cd go_client
go test ./...
```

Патч перебирает все полученные TURN-адреса по очереди при повторных попытках воркера. Он никого не заносит в чёрный список. Таймаут рукопожатия клиента сокращён с 50 до 12 секунд; сервер закрывает неответившее рукопожатие через 8 секунд. Android-клиент передаёт производителя и модель в новом необязательном поле GETCONF. Старые клиенты продолжат работать и показывать только ID устройства.

Имя устройства нельзя извлечь из HWID: HWID служит идентификатором. Пользовательское имя в панели имеет приоритет над именем, присланным клиентом.
