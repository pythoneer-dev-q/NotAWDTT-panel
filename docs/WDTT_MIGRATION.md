# Миграция из другой базы WDTT

В панели откройте «Резервные копии» → «Миграция из WDTT» и выберите исходный `panel.db`. Панель покажет число доступных к переносу пользователей и конфликты. После просмотра нажмите «Импортировать доступных».

Переносятся пользователи, привязки и ключи устройств, лимиты, сроки действия, счётчики трафика и идентификаторы подписок. Главный пользователь и настройки исходной панели не заменяют текущие. При совпадении пароля, ID подписки, ID устройства или VPN-адреса пользователь остаётся в списке конфликтов и не переносится. База или файл, изменённые после предпросмотра, требуют нового предпросмотра.

Вкладка «Telegram-бот» в настройках панели позволяет сохранить токен BotFather, ID администраторов, лимиты новых пользователей и запустить или остановить встроенного бота. Пустое поле токена при повторном сохранении сохраняет прежний токен.

Переменная `WDTT_MAX_DEVICES_PER_USER` задаёт глобальный предел устройств для обычных пользователей. При раздельном запуске панели и нод задайте одинаковое значение в окружении каждого процесса.

RAW остаётся доступным другим клиентам. Переключатель «RAW для других клиентов» находится в редакторе WDTT на странице «Протоколы (RAW/UDP)»; для ранее отключённой конфигурации включите его и сохраните подключение. Панель показывает, когда RAW выключен.
