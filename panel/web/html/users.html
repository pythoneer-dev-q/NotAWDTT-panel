Полноценный RESTful API (в стиле Remnawave) с авторизацией через Bearer Token или API Key без обязательных куки и CSRF.
[[ apiKey || 'Загрузка...' ]] Скопировать
Заголовок: X-API-Key: [[ apiKey ]] или Authorization: Bearer [[ apiKey ]]
1. Поиск и получение списка пользователей: 
curl -s -H "X-API-Key: [[ apiKey ]]" "[[ apiOrigin ]]/api/users?q=test&status=active"
2. Создание пользователя: 
curl -X POST -H "X-API-Key: [[ apiKey ]]" -H "Content-Type: application/json" \
  -d '{"comment":"Client1","total_gb":50,"max_devices":2}' "[[ apiOrigin ]]/api/users"
3. Блокировка и Активация: 
curl -X POST -H "X-API-Key: [[ apiKey ]]" "[[ apiOrigin ]]/api/users/PASSWORD/block"
curl -X POST -H "X-API-Key: [[ apiKey ]]" "[[ apiOrigin ]]/api/users/PASSWORD/activate"
4. Сброс трафика и Удаление: 
curl -X POST -H "X-API-Key: [[ apiKey ]]" "[[ apiOrigin ]]/api/users/PASSWORD/reset-traffic"
curl -X DELETE -H "X-API-Key: [[ apiKey ]]" "[[ apiOrigin ]]/api/users/PASSWORD"
